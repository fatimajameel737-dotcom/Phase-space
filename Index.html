Phase Space of a Two-Particle System

Two particles of mass m constrained to move on a line of length L

System Parameters

1. Configuration Space

Coordinates: (x₁, x₂)
0 ≤ x₁ ≤ L
0 ≤ x₂ ≤ L
Configuration Space = L²

2. Momentum Space

Coordinates: (p₁, p₂)
E₀ = p₁²/(2m) + p₂²/(2m)
p₁² + p₂² = 2mE₀
R = √(2mE₀) = 4.47

3. Complete Phase Space

Phase-space coordinates: (x₁, x₂, p₁, p₂)
Configuration-space dimension = 2
Momentum-space dimension = 2
Total Phase-space dimension = 4
Constant-energy phase space: [0,L]² × Circle(R)
Configuration Space Each particle has one position coordinate. Therefore x₁ and x₂ form a 2D square.
Momentum Space The energy condition produces a circle in the p₁-p₂ plane.
Phase Space The complete state requires four coordinates: x₁, x₂, p₁ and p₂.
